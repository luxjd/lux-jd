================================================================================
  LUXJD — HOW TO START TESTING
  Step-by-step guide from zero to full pipeline test
  May 2026
================================================================================


PREREQUISITES
─────────────
  1. Dev server running:          npm run dev
  2. Database running:            npx prisma db push
  3. .env.local has:
     - OPENROUTER_API_KEY         (Claude access)
     - APIFY_API_KEY              (scrapers — invoices paid!)
     - DATABASE_URL               (Postgres)
     - SESSION_SECRET             (32+ chars)
     - AUTH_EMAIL / AUTH_PASSWORD  (login)
     - SMTP_HOST / SMTP_USER / SMTP_PASS  (email — optional)
  4. Login at http://localhost:3000/login


================================================================================
  TESTING ORDER — Follow this exact sequence
================================================================================

  The agents have dependencies. Test in this order:

  Step 1: Dashboard .......................... 5 min
  Step 2: Valuation Agent (standalone) ....... 10 min
  Step 3: DE Market Agent .................... 15 min (includes scan time)
  Step 4: JP Sourcing Agent .................. 10 min (includes scan time)
  Step 5: Orchestrator ....................... 5 min
  Step 6: Logistics Agent .................... 10 min
  Step 7: Listing Agent ...................... 5 min
  Step 8: Concierge Agent .................... 5 min
  Step 9: Finance Agent ...................... 5 min
  Step 10: Full Lifecycle Test ............... 15 min
                                               ──────
  Total:                                       ~85 min


================================================================================
  STEP 1: DASHBOARD (5 min)
================================================================================

  URL: http://localhost:3000/dashboard

  CHECK:
  [ ] Page loads without errors
  [ ] 4 KPI cards visible (Active Vehicles, Capital, P&L, Leads)
  [ ] Pipeline Overview shows all 10 stage icons
  [ ] Agent Status shows all 7 agents with LIVE/IDLE badges
  [ ] Quick Action buttons work (click each, verify navigation):
      - Scan Market → /agents/de-market
      - Scan Japan → /agents/jp-sourcing
      - Valuate → /agents/valuation
      - Evaluate → /agents/orchestrator
  [ ] FX rate shows a number (e.g., ¥186.88)
  [ ] Sidebar shows agents in pipeline order:
      DE Market → JP Sourcing → Orchestrator → Logistics →
      Listing → Concierge → Finance

  EXPECTED: All sections render. Numbers may be 0 if agents haven't run.


================================================================================
  STEP 2: VALUATION AGENT — Standalone (10 min)
================================================================================

  URL: http://localhost:3000/agents/valuation

  TEST A: Upload an auction sheet
  ─────────────────────────────────
  [ ] Drag+drop a JPEG auction sheet (use src/auction_sheets/1.jpeg)
  [ ] Click "Extract Data"
  [ ] Wait for extraction (~30-60 seconds)
  [ ] Verify extracted data cards appear:
      - Make: Porsche
      - Model: 911
      - Grade: Carrera T
      - Year: 2025
      - Mileage shows a number
      - No internal fields visible (no "fieldConfidence", no "_deepParse*")
  [ ] Mileage label shows "km" or "miles" (not both)

  TEST B: Fill missing fields + submit valuation
  ──────────────────────────────────────────────
  [ ] Fill any missing required fields (asking price, color, etc.)
  [ ] Click "Submit for Valuation"
  [ ] Wait for report (~30-60 seconds)
  [ ] Verify report sections:
      - Vehicle Summary
      - Market Analysis (comparable listings)
      - Landed Cost (15 line items)
      - Margin Analysis (3 scenarios)
      - Risk Assessment (6 dimensions)
      - Recommendation: BUY / REVIEW / PASS
      - Max Bid JPY shown

  TEST C: Check extraction accuracy (automated)
  ───────────────────────────────────────────────
  Run in terminal:
    node --env-file=.env.local \
      --import ./src/lib/agents/valuation/test-loader.js \
      src/lib/agents/valuation/calibration-test.js --sheet=1.jpeg

  [ ] Test completes without crash
  [ ] Accuracy reported (expect ~85%+)

  ────────────────────────────────
  [ ] Click on "Ferrari 488 GTB" card

  [ ] Check sections:

      - Comparable Listings table (with clickable links)
      - Specification Premiums (color + option premiums)
      - Margin Calculator (enter a JPY price, verify margin calculation)

  TEST C: Verify other models load
  ─────────────────────────────────
  [ ] Go back, click on another model (e.g., "Mercedes-AMG GT R")
  [ ] Verify data loads correctly

================================================================================

  This tests the COMPLETE vehicle lifecycle from discovery to sale.

  1. START: DE Market

================================================================================
  COMMON ISSUES & FIXES
================================================================================

  ISSUE: "AI service not configured"
  FIX:   Add OPENROUTER_API_KEY to .env.local

  ISSUE: All scrapers return 403 "Too many outstanding invoices"
  FIX:   Pay Apify invoice at console.apify.com → Billing

  ISSUE: DE Market model detail shows "No data available"
  FIX:   Run a full market scan first. Data persists in DB.

  ISSUE: JP Sourcing shows 0 BUY, all REVIEW/PASS
  FIX:   1. Ensure DE Market scan completed (JP Sourcing needs prices)
         2. Check that Apify is not blocked (403 errors)
         3. Risk thresholds: BUY requires risk ≤ 3.0 (was fixed from 2.0)

  ISSUE: Orchestrator shows 0 APPROVED, all REJECTED
  FIX:   Risk threshold was 2.0, fixed to 3.0. Re-evaluate opportunities.

  ISSUE: Dashboard KPI cards all show 0
  FIX:   Run agents first: DE Market scan → JP Sourcing scan → Evaluate

  ISSUE: Login returns "Invalid or missing CSRF token"
  FIX:   Use the web form at /login, not direct API calls

  ISSUE: Extraction shows internal fields (fieldConfidence, _deepParse*)
  FIX:   Already fixed — these are hidden via HIDDEN_FIELDS in ValuationForm.js

  ISSUE: Mileage shows wrong value (e.g., 2,567 → 56,762)
  FIX:   Zone mileage extractor enabled by default. If still wrong,
         check if the sheet shows マイル (miles) — raw value preserved.

  ISSUE: Console shows "[llm] sonnet 1200+300 tokens = $0.0081"
  FIX:   Not an issue — this is LLM cost tracking. Check total at
         /api/agents/valuation/cost
