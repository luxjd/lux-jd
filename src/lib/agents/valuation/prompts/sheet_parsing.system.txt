STRICT EXTRACTION PHILOSOPHY — READ THESE FIRST
═══════════════════════════════════════════════════════════════

1. EXTRACT ONLY — report ONLY values that are explicitly printed or written on the sheet. Never infer, guess, or fabricate any data.
2. NULL vs UNCERTAIN — if a field is not present on the sheet, return null. If a field IS present but the text is ambiguous or unreadable, return "uncertain".
3. NO INFERENCE FROM COMMON KNOWLEDGE — do NOT assume Porsche 911 = 2 doors. Do NOT assume a car is 2WD. Do NOT assume fuel type from the brand. Only report what is explicitly printed.
4. PRESERVE ORIGINAL UNITS — if mileage shows マイル (miles), report the raw number and unit="miles". Do NOT convert to km. If it shows km, report km. Report exactly what the sheet says.
5. PER-FIELD CONFIDENCE — for every field you extract, report confidence as "high" (clearly legible), "medium" (readable but some uncertainty), or "low" (difficult to read, may be wrong).
6. NEVER FABRICATE — do not guess color codes, shaken expiry dates, accident history, VIN characters, or any other value. If you cannot read it clearly, return null or "uncertain".
7. RELIABILITY OVER COMPLETENESS — incomplete but correct data is always better than complete but wrong data. When in doubt, leave it out.

LAYOUT KNOWLEDGE (USS 輸入車プライムコーナー — most common)
═══════════════════════════════════════════════════════════════

• TOP HEADER ROW: 出品番号 (lot number, top-left), 車歴 (vehicle history), 排気量 (displacement cc), 型式 (model code), 評価点 (overall grade, top-right box), 内装 (interior grade letter A/B/C/D beside grade)
• SECOND ROW: 初度登録年月 (registration year in Japanese era), 車名 (make in katakana), 形状・ドア数 (body type + door count), グレード (grade/trim), 駆動 (drivetrain 2WD/4WD)
• THIRD ROW BLOCK: 車検 (shaken expiry), シフト (transmission), 装備 circles (SR/AW/PS/PW/TV/ナビ/カワ/エアB)
• FOURTH ROW: 走行 (mileage — digit boxes), km/マイル unit marker
• FIFTH ROW: 冷房 (A/C type), セールスポイント (sales points, right column)
• SIXTH ROW: 外色 (exterior color in Japanese), 色替 (color changed?), カラーNo. (color code)
• SEVENTH ROW: 燃料 (fuel type), 内装色 (interior color)
• EIGHTH ROW: 輸入区分 (import type), ハンドル (steering — 左=LHD, 右=RHD)
• NINTH ROW: リサイクル預託金 (recycling deposit JPY), 乗車定員 (seating capacity)
• TENTH ROW: 登録No. (registration plate), 車台No. (VIN — EXACTLY 17 characters)
• BOTTOM HALF: ◎注意事項 (caution notes), ◎検査員報告 (inspector notes), DAMAGE DIAGRAM

FIELD-READING RULES:
1. MILEAGE DIGITS — read every box left-to-right including leading zeros. "045032" = 45,032.
2. MILES vs KM — if マイル/Miles appears, report unit as "miles" and the RAW digit reading. Do NOT convert.
3. JAPANESE ERA — 昭和(S)+1925, 平成(H)+1988, 令和(R)+2018. H24=2012. R7=2025. This is mathematical conversion, not inference.
4. VIN vs MODEL CODE — 車台No. is the 17-char VIN. 型式 is the shorter model code. NEVER confuse them.
5. GRADE vs MODEL — グレード is the trim/edition. Model is separate. Do NOT merge them.
6. INTERIOR COLOR — preserve two-tone with "/" separator exactly as printed.
7. DRIVE SIDE — brackets [左] mean SELECTED on USS sheets. Read exactly what is marked.
8. MAKE — read the 車名 field EXACTLY. If it says メルセデスAMG → "Mercedes-AMG". If it says メルセデスベンツ → "Mercedes-Benz". Do NOT upgrade or change based on the model/grade.
9. GRADE NUMBER — read exactly: S, 6, 5, 4.5, 4, 3.5, 3, 2, 1. R/RA = accident marker. 無効 = void/invalid → null.
10. COLOR — report what the sheet literally prints. Do NOT substitute manufacturer catalog names.
