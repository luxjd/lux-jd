═══════════════════════════════════════════════════════════════
STRICT RULES — VIOLATIONS CAUSE REJECTION
═══════════════════════════════════════════════════════════════

1. EXTRACT ONLY what is explicitly printed on the sheet. Never infer or guess.
2. If a field is not on the sheet → null. If present but unreadable → "uncertain".
3. Do NOT assume values from common knowledge (e.g. do NOT assume door count, drivetrain, or fuel type based on the model name — only report if explicitly printed).
4. PRESERVE ORIGINAL UNITS — if mileage shows マイル/Miles, report the raw number and set mileage_unit="miles". Do NOT convert to km.
5. For Japanese text fields: extract BOTH the original Japanese AND the English translation.
6. Report confidence per field: "high" (clearly legible), "medium" (readable, some uncertainty), "low" (hard to read, may be wrong).
7. Never fabricate color codes, VIN characters, dates, or specs you cannot clearly read.

═══════════════════════════════════════════════════════════════
FIELD EXTRACTION GUIDE
═══════════════════════════════════════════════════════════════

AUCTION HOUSE & LOT:
• auction_house: Header text. USS sub-corners (輸入車プライムコーナー etc.) → just "USS".
• lot_number: 出品番号 — top-left, numeric.

VEHICLE IDENTITY (read each field INDEPENDENTLY from its own label):
• make: 車名 field in katakana. Read EXACTLY what is printed. メルセデスAMG="Mercedes-AMG", メルセデスベンツ="Mercedes-Benz", ポルシェ="Porsche", フェラーリ="Ferrari", ジャガー="Jaguar", アウディ="Audi", ベントレー="Bentley", マセラティ="Maserati", ランボルギーニ="Lamborghini", ロールスロイス="Rolls-Royce", マクラーレン="McLaren", BMW="BMW". Do NOT change the make based on the grade or model fields.
• model: Base model name from the model field. Examples: "GT", "911", "R8 Spyder", "SL550", "G-Class", "CLS Class", "XK". Do NOT include grade/trim here.
• grade: グレード field — trim + edition. Read verbatim. Preserve multi-digit numerals: "130th" must NOT become "10th" or "30th".
• model_code: 型式 field — e.g. "CBA-190378". This is NOT the VIN.

YEAR (mathematical conversion, not inference):
• year: Convert Japanese era from 初度登録年月: S+1925, H+1988, R+2018. Show the math.
• year_era: Raw era string — "H28", "R7", etc.

MILEAGE (highest-priority precision field):
• mileage_reading: 走行 field digit boxes. Read EVERY box left-to-right including leading zeros. Report the RAW number.
• mileage_digits: Digit string including leading zeros, e.g. "009816".
• mileage_unit: Check near digit boxes for km or マイル/Miles/Mile. Report "km" or "miles". Do NOT convert between units.

TECHNICAL SPECS (only if explicitly printed):
• displacement_cc: 排気量 — only if printed on the sheet.
• transmission: シフト — AT/FAT/CVT/CAT=AUTOMATIC, MT/F5/F6=MANUAL, DCT/PDK/SMG as-is. Only if printed.
• fuel_type: 燃料 — ガソリン=PETROL, 軽油=DIESEL, etc. Only if printed.
• drive_side: ハンドル — read the selection marker (circle, brackets, underline). 左=LHD, 右=RHD. [左] on USS = SELECTED. Only if clearly marked.

COLORS (extract original Japanese AND translation):
• exterior_color: English translation of what 外色 prints. Report the sheet's own words — do NOT substitute catalog names.
• exterior_color_japanese: Exact Japanese characters from 外色, verbatim.
• color_code: カラーNo. — only if clearly printed.
• interior_color: 内装色 — preserve two-tone with "/" exactly as printed.

GRADES (read the exact character/number):
• overall_grade: 評価点 — the number or letter in the grade box. S/6/5/4.5/4/3.5/3/2/1. R/RA = accident marker (NOT a numeric grade → set to null, set accident_history=true). 無効 = void → null.
• interior_grade: 内装 — single letter A/B/C/D. NOT the color.

OTHER FIELDS (only if explicitly visible):
• import_type: 輸入区分 — only if printed.
• accident_history: 修復歴 — 有=true, 無=false. Only if explicitly marked. Do NOT infer from damage codes.
• service_book_present: 保証書付 — 有=true, 無=false. Only if marked.
• shaken_expiry: 車検 — convert era to "YYYY-MM" (mathematical). Only if date is printed.
• registration_plate: 登録No. — verbatim with kanji/hiragana. Only if printed.
• vin: 車台No. — EXACTLY 17 characters. If you cannot read all 17 clearly, return "uncertain". NEVER return the model code here.
• recycling_deposit_jpy: リサイクル預託金 — only if printed.
• dimensions: 長さ/幅/高さ — only if printed. Report in mm (cm values ×10).
• seating_capacity: 乗車定員 — only if printed.
• door_count: ドア数 — only if explicitly printed (e.g. "3D", "2D"). Do NOT infer from body type.
• drivetrain: 駆動 — only if explicitly printed (2WD/4WD). Do NOT assume.

NOTES & DAMAGE:
• equipment_translated: Only equipment icons that are clearly circled/marked.
• sales_points, caution_notes, inspector_notes: Translated to English from Japanese text.
• damage_codes: Only codes clearly written on the diagram.
