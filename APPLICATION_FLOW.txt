OVERVIEW
--------
After login, the user lands on the Dashboard which shows KPIs (active vehicles,
portfolio value, P&L, active leads), pipeline overview, and agent health status
for all 7 agents. From there, the flow follows a linear chain of specialized
AI agents, each feeding into the next.

Business model: Buy undervalued luxury cars at Japanese auctions, import to
Germany, sell on the German market. Target gross margin: EUR 15,000-60,000
per vehicle (20-50%). Cycle time: 10-16 weeks per vehicle.


================================================================================
  AGENT #0 — VALUATION AGENT (Standalone)
================================================================================

  Purpose:   Quick standalone vehicle valuation — no other agent needed.
  Location:  Dashboard → Valuate (or Agent Hub → Valuation Agent)

  Input:     Upload vehicle specs (make, model, year, mileage, asking price JPY)
             + optional photos (up to 30) + auction sheet + additional docs
             (service booklet, CoC, build sheet)

  Process:   9-step pipeline running in 30-60 seconds:
             1. Input validation & enrichment (Claude Haiku)
             2. Photo & condition analysis (Claude Vision Sonnet) — parallel
             3. Auction sheet parsing (multi-pass, 41 fields) — parallel
             4. Market research / scraping (mobile.de + AutoScout24) — parallel
             5. FX rate fetch (JPY/EUR, cached 1 hour) — parallel
             6. Landed cost calculation (15 line items, Decimal.js)
             7. Margin calculation (pessimistic / base / optimistic)
             8. Risk assessment (6 dimensions, rule-based deterministic)
             9. Final recommendation (Claude Sonnet, depends on steps 7+8)

  Auction Sheet Extraction (sub-pipeline within step 3):
             - Two-tier strategy: cheap unified pass → fallback per-field retry
             - Deterministic JP→EN dictionary (400+ terms, no LLM translation)
             - Strict schema validation (enums, ranges, cross-field checks)
             - Zone-crop mileage extractor (3-model consensus)
             - Image preprocessing (upscale, contrast, sharpen)
             - Per-field confidence: high / medium / low
             - 88.6% accuracy on 13 USS calibration sheets
             - 18 of 32 core fields at 100% accuracy
             - New P0 fields: auction prices, results, service record history

  Output:    ValuationReport containing:
             - vehicle_summary (enriched: full name, engine spec, MSRP, options)
             - condition_assessment (exterior/interior scores, damage, panels)
             - market_analysis (estimated sale price, 7 adjustment factors,
               comparable listings, demand velocity, trend)
             - landed_cost (15 line items: purchase → registration)
             - margin_analysis (3 scenarios, break-even, confidence)
             - risk_assessment (6 dimensions: condition, provenance, TUV,
               market, currency, capital — weighted overall score)
             - recommendation (BUY / REVIEW / PASS, max_bid_jpy, reasoning)

  Rules:     BUY  = margin >= EUR15k AND >= 20% AND confidence >= 0.70
                     AND risk <= 3.0 AND no HIGH individual risks
                     AND pessimistic margin > EUR0
             REVIEW = meets margin but confidence 0.50-0.70, OR risk 3.0-4.0,
                      OR one HIGH risk, OR borderline margin (within 15%)
             PASS = margin below threshold, OR confidence < 0.50,
                    OR risk > 4.0, OR multiple HIGH risks

  Action:    "Send to Pipeline" button adds approved vehicles to Logistics.

  APIs:      POST /api/agents/valuation/valuate — full valuation
             POST /api/agents/valuation/extract-data — sheet extraction only
             POST /api/agents/valuation/parse-sheet — quick single-pass
             GET  /api/agents/valuation/history — past valuations + stats
             GET  /api/agents/valuation/cost — LLM usage/cost tracking
             POST /api/agents/valuation/calibration — record actual sale price
             GET  /api/agents/valuation/calibration — prediction accuracy stats

  Why first: Immediate standalone value, validates core capabilities,
             can be used before any other agent is running.

  AGENT #1 — DE MARKET AGENT (Must Run First for Pipeline)
================================================================================

  Purpose:   Build real-time German/European market intelligence for all
             target models. Answers: "What is this car worth in Germany?"
  Location:  Dashboard → AI Agents → DE Market Agent
  Depends:   Nothing — this is the data foundation.

  Input:     "Full Scan" button triggers scraping of all 20 target models.

  Target Models (20):
             Ferrari      — 488 GTB, F12 Berlinetta, Roma
             Mercedes-AMG — GT R, G63, C63, E63
             Porsche      — 911 GT3 (992), 718 Cayman GT4, Cayenne Turbo GT
             Jaguar       — F-Type R
             Bentley      — Continental GT
             Lamborghini  — Huracan STO
             Aston Martin — DB11 V12, Vantage
             BMW M        — M3 Competition, M4 Competition
             Range Rover  — Sport SVR
             Maserati     — MC20

  Data Sources:
             Primary:     mobile.de + AutoScout24 (Apify proxy scrapers)
             Specialist:  elferspot.com (Porsche), classicdriver.com (exotics)
             Auction:     RM Sotheby's, Bonhams, Artcurial (price anchoring)
             Dealers:     Saker, Luft Auto, Exclusive Cars, Hollmann
             Reference:   Hagerty valuations, Classic Analytics indices

  Process:   Per model:
             1. Scrape listings from all sources (parallel)
             2. Merge, deduplicate, remove outliers (IQR method)
             3. Calculate price statistics (mean, median, P25, P75)
             4. Score demand velocity (0-100, based on days-on-market)
             5. Detect trends (7d / 30d / 90d regression)
             6. Analyze specification premiums via Claude
                (color, options, editions, configuration rarity)
             7. Track competitor inventory and pricing strategy
             8. Generate Target Vehicle Report (TVR)

  Output:    MarketSnapshot per model stored in DB:
             - Market value range (EUR): median, P25, P75
             - Velocity / demand score (0-100)
             - Confidence percentage
             - Trend direction + magnitude
             - Specification premium/discount modifiers
             - Competitor intelligence
             - Recommended max landed cost
             - Data freshness timestamp

  Schedule:  Every 6 hours (cron). Manual "Full Scan" on demand.

  Why first: JP Sourcing, Listing, Orchestrator, and Valuation agents all
             need German market pricing data to calculate margins, set
             listing prices, and make purchase decisions.


================================================================================
  AGENT #2 — JP SOURCING AGENT
================================================================================

  Purpose:   Find undervalued luxury vehicles at Japanese auctions.
  Location:  Dashboard → AI Agents → JP Sourcing Agent
  Depends:   DE Market Agent (needs German prices to calculate margins).

  Input:     "Scan Japanese Auctions" button triggers auction search.

  Data Sources:
             USS (Used Car System Solutions) — largest, ~30% market share
             TAA (Toyota Auto Auction) — Toyota/Lexus + other brands
             HAA (Honda Auto Auction)
             JU (Japan Used Car Dealers Union)
             BH Auction — high-end exotic focus
             Arai — sports car specialist
             Goo-net.com — dealer inventory aggregator
             carsensor.net — dealer inventory
             Specialist brokers (SBI Motor Japan, etc.)

  Process:
             1. Load target models + pricing from DE Market data
             2. Scan all Japanese auction sources (parallel)
             3. Filter: LHD preferred, auction grade >= 4.0,
                mileage < 50,000 km, service history available
             4. Parse auction sheets via Claude Vision OCR
                - Extract 41 fields (grades, damage, service, pricing)
                - Score condition confidence (0-1)
             5. Provenance verification (high-value vehicles):
                - Matching numbers (engine/chassis)
                - Original color vs build sheet
                - Service history completeness + dealer stamps
                - Limited edition numbering
             6. Calculate full landed cost per vehicle (15 line items)
             7. Calculate margins against DE Market prices
             8. Apply risk flags:
                - RHD penalty (-15% market value)
                - Auction grade < 4.0
                - Missing service history
                - Non-EU spec issues
                - No Certificate of Conformity
             9. Rank all candidates by risk-adjusted margin

  Output:    Per vehicle:
             - STRONG_BUY / BUY / REVIEW / PASS recommendation
             - JP auction price + DE market value
             - Full landed cost breakdown (15 items)
             - Expected margin (EUR + %)
             - Risk score (5 dimensions: condition, market, provenance,
               logistics, specification)
             - AI investment thesis
             - Recommended max bid (JPY)

  Metrics:   Count of Strong Buys, Buys, Reviews, Passes per scan.


================================================================================
  AGENT #3 — ORCHESTRATOR (Supreme Agent — Decision Gateway)
================================================================================

  Purpose:   Makes the final purchase decision. Central command and control.
  Location:  Dashboard → AI Agents → Orchestrator
  Depends:   JP Sourcing (recommendations) + DE Market (prices) + Finance (capital).

  Input:     Takes BUY and STRONG_BUY recommendations from JP Sourcing.
             "Evaluate" button runs the decision engine.

  7-Step Decision Engine:
             Step 1: Margin Check      — margin >= EUR 15,000 AND >= 20%?
             Step 2: Confidence Check   — confidence score >= 0.70?
             Step 3: Brand Concentration — brand < 30% of portfolio?
             Step 4: Capital Check      — total deployed < 80% of available?
             Step 5: Risk Flags         — no critical risk flags?
             Step 6: Timing Check       — favorable sale window?
                     (avoid convertibles in Oct, GTs arriving peak summer)
             Step 7: Final Verdict      — all steps pass?

  Output:    Per vehicle:
             - AUTO_APPROVE → proceed to purchase with max_bid_jpy
             - HUMAN_REVIEW → flag for manual decision
             - REJECT → do not pursue

  Displays:
             - Agent Health Monitor (all 7 agents: HEALTHY/DEGRADED/DOWN/IDLE)
             - Portfolio State (vehicles count, capital deployed, remaining)
             - Brand Concentration chart (>30% triggers warning)
             - Decision History with full 7-step breakdown

  Human-in-the-loop required for:
             - Purchases > EUR 80,000
             - Any risk flags present
             - Price deviation > 10% from market
             - Offers below 92% of asking
             - Complaints or legal issues
             - Process deviations

  All decisions logged to audit_logs table for compliance.


================================================================================
  AGENT #4 — LOGISTICS AGENT (10-Stage Import Pipeline)
================================================================================

  Purpose:   Track each vehicle through the entire import process.
  Location:  Dashboard → AI Agents → Logistics Agent (or Pipeline Kanban)
  Depends:   Orchestrator (approved vehicles enter the pipeline).

  10 Pipeline Stages (as implemented in code):
             Stage 1:  SOURCED        — Identified at Japanese auction
             Stage 2:  PURCHASED      — Won at auction, payment confirmed
             Stage 3:  JP_TRANSPORT   — Japan inland transport to export port
             Stage 4:  AT_PORT_JP     — At Japanese port, pre-loading inspection
             Stage 5:  IN_TRANSIT     — Ocean freight (4-6 weeks Japan → DE)
             Stage 6:  AT_PORT_DE     — Arrived Hamburg/Bremerhaven
             Stage 7:  CUSTOMS        — Import declaration, duty + VAT payment
             Stage 8:  WORKSHOP       — Maintenance, repairs, preparation
             Stage 9:  TUV            — Einzelabnahme technical inspection
             Stage 10: READY_FOR_SALE — Cleared for listing

  Rules:
             - Stages advance forward ONLY (no skip, no reversal without override)
             - Every transition is timestamped and logged
             - Photo documentation required at: PURCHASED, AT_PORT_JP,
               AT_PORT_DE, TUV, READY_FOR_SALE
             - Prerequisites enforced:
               AT_PORT_JP → IN_TRANSIT: requires pre-loading inspection
               CUSTOMS → WORKSHOP: requires duty payment confirmation
               TUV → READY_FOR_SALE: requires TUV pass certificate

  Features:
             - Stage summary with vehicle counts per stage
             - Individual vehicle cards with progress bars
             - "Advance Stage" buttons for manual progression
             - "Auto Advance" for bulk stage progression
             - Shipment tracking (vessel name, container, route, insurance)
             - TUV appointment management
             - ETA calculations per route
             - Cost tracking per stage

  Documents Required:
             - Export Permission Certificate (EPC)
             - Radiation inspection certificate (post-2011 Japan exports)
             - Bill of lading
             - Marine insurance certificate
             - Zollanmeldung (customs declaration)
             - Certificate of Conformity (CoC) for TUV
             - TUV pass certificate

  Timeline:  Typically 6-12 weeks per vehicle (end to end).

  Output:    Vehicle status updates, pipeline events logged to DB.
             Vehicles reaching READY_FOR_SALE become available to Listing Agent.


================================================================================
  AGENT #5 — LISTING AGENT (Multi-Platform Publishing)
================================================================================

  Purpose:   Create and manage premium listings across European marketplaces.
  Location:  Dashboard → AI Agents → Listing Agent (or Listings page)
  Depends:   Logistics Agent (vehicle must reach READY_FOR_SALE stage).
             DE Market Agent (for competitive pricing data).

  Process:
             1. Takes READY_FOR_SALE vehicles from Logistics
             2. Generates descriptions via Claude Sonnet:
                - 800-1200 words, German + English
                - Platform-optimized formatting
                - SEO keywords for mobile.de
                - Narrative provenance for classicdriver
                - Highlights and notable factory options
                - Prompts loaded from external .txt files
             3. Sets pricing strategy:
                - Initial price at P60-P75 of market
                - Graduated reduction schedule:
                  Day 0-14:  Hold price
                  Day 14-28: Reduce 3-5%
                  Day 28-42: Reduce another 3-5%
                  Day 42+:   Strategic review / Orchestrator intervention
             4. Publishes to platforms:
                - mobile.de (primary, dealer account)
                - AutoScout24 (primary, cross-border visibility)
                - elferspot.com (Porsche-specific)
                - classicdriver.com (premium/collector)
                - Company website (secondary)
                - Instagram (brand building, aspirational content)

  Output:    Active listings with:
             - Platform links
             - Price history (all reductions tracked)
             - View/inquiry counts per platform
             - Days on market

  Metrics:   Active listings, sold count, total created, avg days to sale.


================================================================================
  AGENT #6 — CONCIERGE AGENT (Customer Interaction)
================================================================================

  Purpose:   Handle all buyer inquiries with AI-powered expert responses.
  Location:  Dashboard → AI Agents → Concierge Agent (or Leads page)
  Depends:   Listing Agent (inquiries come from listed vehicles).

  Process:
             1. Receives inquiry from marketplace platform
             2. Classifies buyer type:
                - COLLECTOR — high value, enthusiast knowledge
                - TRADE — dealer/reseller, price-focused
                - BROWSER — casual interest / information seeker
                - UNKNOWN — insufficient data
             3. Scores lead (0-100) based on:
                - Inquiry depth and specificity
                - Vehicle match quality
                - Buyer type classification
             4. Generates expert response via Claude Sonnet:
                - Enthusiast-level vehicle knowledge (option codes,
                  engine types, performance packages)
                - Brand-specific terminology
                - Multi-language (DE / EN / FR / IT / NL)
                - Responds within 10 minutes
             5. Handles negotiation within parameters:
                - Present asking price with justification
                - Evaluate counter-offers against minimum floor
                - Accept, counter, or escalate to human
             6. Sends response via email (SMTP)

  Escalation triggers (requires human):
             - Offers below 90% of listing price
             - Part-exchange / trade-in proposals
             - Independent inspection requests
             - Complaints or legal language
             - Vehicle history documentation requests

  Output:    Lead records with conversation threads, scores, status.

  Lead Statuses: NEW → QUALIFIED → CONTACTED → CONVERTED → LOST
                 (or ESCALATED at any point)


================================================================================
  AGENT #7 — FINANCE AGENT (Runs Continuously)
================================================================================

  Purpose:   Track all financial aspects across the entire portfolio.
  Location:  Dashboard → AI Agents → Finance AI (or Finance page)
  Depends:   All other agents (aggregates financial data from entire pipeline).

  Capabilities:

  1. Per-Vehicle P&L:
             - Purchase cost (JPY + EUR equivalent at actual FX rate)
             - All landed costs itemized (15 line items)
             - Listing price / sale price
             - Gross margin (EUR + %)
             - Net margin after operational expenses
             - Compare estimated vs actual costs (agent accuracy tracking)

  2. Portfolio Dashboard:
             - Total vehicles in pipeline
             - Capital deployed vs available (80% limit)
             - Realized P&L (sold vehicles)
             - Unrealized P&L (in-pipeline vehicles, mark-to-market)
             - Portfolio health score

  3. FX Monitoring:
             - Hourly JPY/EUR rate fetch
             - Moving averages (7d, 30d, 90d)
             - Volatility tracking (30-day std deviation)
             - Alert thresholds:
               > 2% deviation from 30d moving average
               Threshold crossing (e.g., Y160/EUR)
               > 1% daily movement
             - Hedging recommendations when exposure exceeds threshold

  4. Tax Optimization:
             - Differenzbesteuerung (§25a UStG) — margin scheme, VAT on
               profit margin only. Requires no input VAT deduction.
             - Regelbesteuerung — standard taxation, reclaim import VAT
               (19%) but charge full VAT on sale price.
             - Models BOTH options per vehicle, recommends optimal
             - Monthly Umsatzsteuer-Voranmeldung data generation

  5. Cash Flow:
             - VAT reclaim timeline (4-8 week gap after payment)
             - Capital turnover rate
             - Projected cash position (4-8 weeks forward)
             - Alert when reserves drop below safety threshold

  6. Regulatory Monitoring:
             - EU import regulation changes
             - Customs duty rate updates
             - Emissions standards updates
             - German vehicle trading requirements (§38 GewO)

  Output:    Financial reports, FX alerts, tax recommendations.
  Metrics:   Revenue, margins, capital deployed, FX rates, compliance status.
